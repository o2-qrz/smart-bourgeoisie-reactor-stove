# 🏎 Smart-Bourgeoisie (Resilience-Stove) ### *Two-Chamber Automated Off-Grid Reactor with Quantum Air Injection and Cascade Ignition* **Project Overview:** This repository hosts the engineering blueprints and automation logic for a high-efficiency, dual-chamber, grate-less wood stove. Co-developed by the Lead Hardware Architect and Google Gemini AI, this system provides 8-12 hours of automated, off-grid heating. --- ## 📊 Thermal Power & Fuel Efficiency Matrix | Parameter | Configuration: 3+3 Briquettes | Configuration: 6+6 Briquettes | | :--- | :--- | :--- | | **Total Fuel Weight** | 5.0 kg total (2.5 kg/chamber) | 10.0 kg total (5.0 kg/chamber) | | **Net Useful Heat (80% Eff)** | **19.2 kWh** | **38.4 kWh** | | **Active Burn Time** | 3.5 – 4.0 hours | 4.0 – 4.5 hours | | **Total Autonomous Runtime** | **~8 – 10 hours** | **~10 – 12 hours** | | **Avg. Thermal Power** | **~2.2 kW / hour** (15-22 m²) | **~4.0 kW / hour** (35-45 m² zones) | --- ## 📐 Key Design Features * **Dual Hermetic Loading:** Independent chambers with high-temp sealing for zero smoke leakage. * **V-Shaped Fusion Hearth:** Grate-less, 5mm steel design ensures gravity-fed fuel and high-temp vortex combustion. * **6-Hour Pre-Drying Cycle:** A central 2cm air jacket acts as a +150°C heat exchanger, drying the standby chamber's fuel, creating a high-caloric, zero-moisture state, and preventing creosote build-up. * **Arduino Automation:** 12V electromagnetic valves manage quantum-pulse air injection and cascade ignition via nichrome loop. --- ## 💻 Arduino C++ Core Firmware (Snippet) *The complete code handles multi-zone temperature monitoring and automated ignition, which can be found in the repository.
